# Tweeds

Tweeds is the Tinker Works Design System. Use this reference to build interfaces with the Tinker Works colors, typography, and components.

**Foundations / System reference** covers color, typography, spacing, motion, themes, and tokens. **Brand / Tweeds** covers the playbook identity; **Brand / Logo** covers the Tinker Works wordmark. Each page under **Components** includes its API, controls, states, and usage guidance. **Patterns / Common layouts** shows forms, settings, content collections, and search.

## Try a component

1. Change its controls in the Canvas view.
2. Check Paper and Ink with the theme toolbar.
3. Use Tab and the relevant arrow keys to check keyboard access.
4. Review the Accessibility panel and API table.
5. Resize the canvas to check narrow layouts and long labels.

## Use the playbook

Run `pnpm dev` to open the Tweeds playbook. It includes the foundations, component catalog, and patterns. **Examples** contains Common Thread, a separate product example. Its screens and business rules are private to that example and are not part of the public library. Applications consume the library as `@tinker-works/ui`.

## Brand basics

DM Serif Display gives the Tweeds and Tinker Works wordmarks their fuller strokes. The TW monogram remains part of the Tinker Works identity. Instrument Serif is used for editorial and display headings, Space Grotesk for interface and reading text, and IBM Plex Mono for captions and technical details. Cream and charcoal are the default colors. Orange and lime draw attention to a specific action or detail.

The approved brand statement is **From curiosity to real things.**
