Tweeds is the Tinker Works Design System. Use this reference to build interfaces with the Tinker Works colors, typography, and components.

**Foundations / System reference** covers color, typography, spacing, motion, themes, and tokens. **Foundations / Motion** shows the drafting verbs and plots each easing token. **Brand / Tweeds** covers the playbook identity; **Brand / Logo** covers the Tinker Works wordmark. Each page under **Components** includes its API, controls, states, and usage guidance. **Patterns / Common layouts** shows forms, settings, content collections, and search.

## Try a component

1. Change its controls in the Canvas view.
2. Check Paper and Ink with the theme toolbar.
3. Use Tab and the relevant arrow keys to check keyboard access.
4. Review the Accessibility panel and API table.
5. Resize the canvas to check narrow layouts and long labels.

## Use the playbook

Run `pnpm dev` to open the Tweeds playbook. It includes the foundations, component catalog, and patterns. **Examples** contains Common Thread, a separate product example. Its screens and business rules are private to that example and are not part of the public library. Applications consume the library as `@tinker-works/ui`.

## Brand basics

Instrument Serif draws the Tweeds and Tinker Works wordmarks, the TW monogram, and editorial headings, so the identity and the voice come from one hand. Instrument Sans, its companion, carries the interface and reading text. IBM Plex Mono annotates captions, measurements, and technical details. Ink is the default surface and paper the light alternative; every grey between them is a mix of the two. Orange and lime draw attention to a specific action or detail.

The approved brand statement is **From curiosity to real things.**
